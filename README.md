# My To-Do List 🎯

A modern, fast, offline-ready productivity web app designed to help you organize daily goals and stay in flow.

## Key Features

- **Subtasks with Dependency Locks**: Break down complex goals; parent tasks remain locked until all subtasks are finished.
- **Pomodoro Focus Timer**: Built-in 25/5 minute timer attached directly to tasks.
- **Daily Streak & Milestone Trophies**: Gamified productivity tracking with unlockable achievement badges.
- **Sound Studio**: Custom Web Audio synthesis with 4 chime themes and volume control.
- **Hashtags & Smart Filters**: Type `#tags` inside task names to filter instantly.
- **Drag-and-Drop & Mobile Swipes**: Reorder tasks on desktop; swipe cards to complete or delete on mobile.
- **PWA & Offline Ready**: Installable to home screen or desktop with full local storage persistence.
- **System Theme Auto-Sync**: Automatically matches your device's light or dark mode.

## Built With

- HTML5 & Modern ES6+ JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- Web Audio API & Web Share API
- HTML5 Drag and Drop & Touch Events
- LocalStorage Persistence

## Quick Start

Simply open `index.html` in any web browser—no build tools, servers, or dependencies required!
